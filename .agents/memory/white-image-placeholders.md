---
name: White image placeholders
description: How to handle Glam by Dia image areas while approved photos are unavailable.
---

When an image is removed pending client-approved photography, keep its position and dimensions and display a solid white image placeholder. Do not remove the image area or leave it transparent.

**Why:** The user clarified that “blank” means replace the image with a white image, not remove the visual content area.

**How to apply:** Use this for image slots across the site until the user supplies approved replacements. Preserve the logo and non-image UI icons unless separately instructed.
