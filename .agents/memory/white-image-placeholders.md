---
name: White image placeholders
description: How to handle Glam by Dia image areas while approved photos are unavailable.
---

When an image is removed pending client-approved photography, keep its position and dimensions and display a solid placeholder. Use white generally; use light grey for homepage service-card photo areas. Do not remove the image area or leave it transparent.

**Why:** The user clarified that “blank” means replace the image with a visible placeholder, not remove the visual content area. They later requested light grey placeholders for the homepage service-card photos.

**How to apply:** Use this for image slots across the site until the user supplies approved replacements. Preserve the logo and non-image UI icons unless separately instructed.
