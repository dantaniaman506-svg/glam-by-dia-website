---
name: Google review excerpts
description: How to display user-supplied Google review text on the Glam by Dia site.
---

Display only review excerpts the user supplied from Google. Do not invent missing text where Google screenshots truncate a review, and do not present the business's responses as customer reviews. Keep the excerpts static unless the user explicitly asks for a live integration.

**Why:** the user asked for the supplied review text only and has repeatedly preferred a simple site without added APIs.

**How to apply:** retain the reviewer attribution and visible quote excerpt, make review cards link to the Glam by Dia Google Maps listing, and do not imply that static excerpts are live updates.
