# Replit run guide

- Start the web preview with `bun run dev` on port 5000.
- The frontend is a Vite React SPA using React Router; page routes are listed in `src/App.tsx`.
- Booking and contact forms validate in the browser and open a prefilled `mailto:` draft; visitors must tap Send in their email app.
- The site is fully static. Do not add a backend, API, database, or form-submission storage unless the owner asks.
